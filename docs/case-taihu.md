# 案例：6 天环太湖自驾（苏州往返）

> 演示 `Travel Docs` skill（整合版）的完整产出。日期 2026-11-10 至 11-15（6 天 5 晚），3 成人，1 间三人房含早，舒适档，体力好。

## 路线

苏州（起/终）→ 无锡 1 晚 → 宜兴 1 晚 → 湖州 2 晚 → 苏州东山 1 晚 → 同里 → 苏州

顺时针环太湖单向不走回头路，**总里程 355 km / 约 5h08（OSRM 实算）**：60 + 58 + 68 + 0 + 105 + 64 km，最长单日 105 km / 1h25，无一日超 4h。

| 日 | 日期 | 路线 | km/车时 | 住 |
|---|---|---|---|---|
| D1 | 11/10 二 | 苏州→无锡，下午鼋头渚 + 拈花湾 | 60 / 0h56 | 无锡 |
| D2 | 11/11 三 | 无锡→宜兴，善卷洞 + 阳羡溪山 | 58 / 0h52 | 宜兴 |
| D3 | 11/12 四 | 宜兴→湖州，龙之梦动物世界 + 古镇夜游 | 68 / 0h52 | 湖州 1/2 |
| D4 | 11/13 五 | 湖州休整（演艺/马戏），无驾驶 | 0 / — | 湖州 2/2 |
| D5 | 11/14 六 | 湖州→东山，环湖 + 陆巷古村落日 | 105 / 1h25 | 东山 |
| D6 | 11/15 日 | 东山→同里→苏州 | 64 / 1h03 | 到家 |
